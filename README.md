# 🛒 Amazon India Sales Intelligence Dashboard

## 📊 Tools Used
Power BI | DAX | Power Query | CSV

## 📁 Project Overview
Built an end-to-end interactive BI dashboard analyzing 
5,000+ Amazon India transactions across 6 product 
categories (2021–2023)

## 📄 Dashboard Pages
- Page 1 — Executive Summary
- Page 2 — Product Analysis  
- Page 3 — Customer Analytics
- Page 4 — Time Intelligence

## 🔢 DAX Measures
- Total Revenue, Total Profit, Total Orders
- YoY Growth %
- Revenue YTD
- Return Rate %
- Profit Margin %
- Avg Order Value
- Festive Revenue

## 🗂️ Dataset
5000 rows | 33 columns | 2021-2023
Amazon India Sales Data
